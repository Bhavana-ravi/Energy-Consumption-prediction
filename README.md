# ⚡ WattWise Energy Outlook

**WattWise Energy Outlook** is a smart-home energy consumption prediction project that analyzes historical electricity usage and forecasts future consumption using **ARIMA time-series forecasting**.

### 🛠️ Tech Stack

* Python, Pandas, NumPy, ARIMA
* React, JavaScript, HTML, CSS
* Matplotlib

### ✨ Features

* Energy consumption analysis
* Future energy consumption forecasting
* Interactive visualization dashboard
* Smart-home energy insights
